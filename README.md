# SQL Data Analytics Projects
### Exploring Data Analyst salaries, remote opportunities, and in-demand skills

A portfolio of SQL projects using a job-postings dataset to investigate the Data Analyst job market. The analyses examine high-paying roles, the skills attached to those roles, frequently requested skills, salary patterns by skill, and the overlap between skill demand and salary.

The repository is built with **PostgreSQL** and demonstrates practical querying, relational joins, common table expressions, aggregation, and business-focused interpretation.

---

## Project objectives

This project addresses five questions:

1. Which remote Data Analyst job postings have the highest reported annual salaries?
2. Which skills are listed in the highest-paying remote Data Analyst postings?
3. Which skills are most frequently requested in remote Data Analyst postings?
4. Which skills are associated with the highest average salaries?
5. Which skills combine meaningful job-posting demand with higher average salaries?

## Project catalogue

| # | SQL script | Analysis | Techniques |
|---:|---|---|---|
| 01 | [Top-Paying Jobs](1_top_paying_jobs.sql) | Retrieves the 10 highest-paying remote Data Analyst postings with employer and posting details. | Filtering, LEFT JOIN, sorting, LIMIT |
| 02 | [Skills for Top-Paying Jobs](2_top_paying_job_skills.sql) | Identifies the skills associated with the 10 highest-paying postings. | CTE, INNER JOIN, relational analysis |

## Selected findings

The first four scripts include result snapshots from the supplied dataset outputs. These are historical, dataset-specific observations and are not live vacancy or salary data.

- **Highest-paying postings:** the 10 selected postings ranged from **$184,000 to $650,000** in reported annual average salary.
- **Most frequently requested skills:** SQL (7,291), Excel (4,611), Python (4,330), Tableau (3,745), and Power BI (2,609) led the supplied remote-posting results.
- **Skills with high salary averages:** PySpark ($208,172), Bitbucket ($189,155), and Couchbase / Watson ($160,515 each) appeared near the top of the supplied salary-by-skill output.

The fifth analysis, **Optimal Skills**, brings demand and salary together. Its query is included in the repository; its findings should be generated by running it against the project database rather than inferred from the other query outputs.

## Analytical approach

The scripts use a consistent set of filters and relational tables to make the analyses comparable:

- `job_title_short = 'Data Analyst'` selects postings classified as Data Analyst by the dataset.
- `job_work_from_home = TRUE` identifies postings marked as work-from-home for the demand and salary-by-skill analyses.
- `job_location = 'Anywhere'` is used in the top-paying-postings analysis to select postings listed as anywhere.
- Records without a reported annual average salary are excluded from salary calculations.

### Database tables

| Table | Role in the analysis |
|---|---|
| `job_postings_fact` | Job titles, locations, work arrangements, posting dates, and salary information. |

1. Create or connect to a PostgreSQL database containing the four tables listed above.
2. Open the SQL files in pgAdmin or another PostgreSQL-compatible SQL editor.
3. Run the scripts in numerical order (01–05).
4. Inspect the returned records and compare the findings across the five analyses.
5. Rerun the queries when the underlying dataset is updated.

The scripts contain comments describing each business question, analytical approach, and relevant interpretation notes.

## Important considerations

- **Dataset classification:** `job_title_short` is a dataset category. The displayed job title may refer to a specialist, principal, or leadership position.
- **Remote-work filters:** the demand, salary-by-skill, and optimal-skills analyses use the dataset's work-from-home flag. The top-paying-jobs analysis instead uses the `Anywhere` location value.
- **Salary interpretation:** average salary by skill indicates an association in the observed postings; it does not prove that a skill causes higher compensation.
- **Sample-size effects:** skills linked to relatively few postings may have volatile average salaries. The optimal-skills query applies a minimum demand threshold to reduce the influence of very rare skills.
- **Historical results:** the included figures are snapshots from the supplied query outputs. Results may change when the database or source dataset changes.
